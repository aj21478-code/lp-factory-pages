05 / iPhoneからLPを公開

GitHub Pagesで公開します。初回のみGitHubで公開リポジトリを作り、Settings → Pages → Deploy from a branch → main / root を選択してください。GitHubの無料プランで公開可能です。公開したHTMLは誰でも閲覧できます。

初回設定・セキュリティ

GitHubでFine-grained personal access tokenを作り、対象リポジトリだけに Contents: Read and write を許可します。トークンはこの画面で送信時にだけ使用し、保存しません。トークンを他人に渡さないでください。GitHub APIへの直接送信以外に使いません。公開リポジトリには個人情報や未許諾写真を入れないでください。

公開後のURL例： https://ユーザー名.github.io/リポジトリ名/URL名/　反映まで数分かかる場合があります。GitHub Pagesが無効だと404になります。

※ 実在する事業者の写真・ロゴ・文章は許可を得て使用してください。サンプルを公式サイトと誤認させないでください。GA4は実測データのみ表示され、架空の分析数値は生成しません。
